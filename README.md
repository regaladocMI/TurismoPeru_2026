# TurismoPeru_2026

TurismoPeru_2026 es una aplicación web desarrollada como parte del curso de Base de Datos II, orientada a la gestión de información de personas y clientes dentro de un sistema de turismo. El proyecto integra una base de datos SQL Server con una aplicación Flask, permitiendo registrar, listar y administrar personas y clientes de forma centralizada.

El objetivo del proyecto es aplicar de manera práctica los conceptos de bases de datos relacionales, procedimientos almacenados y desarrollo web, dentro de un entorno controlado con control de versiones mediante Git y GitHub. La aplicación permite registrar nuevas personas, visualizar el listado de personas y clientes, y sienta las bases para futuras funcionalidades de edición y eliminación de registros.

Este repositorio contiene el código fuente del proyecto, organizado siguiendo una estructura modular (modelos, controladores, plantillas y conexión a base de datos) que facilita su mantenimiento y escalabilidad. TurismoPeru_2026 forma parte de un ejercicio académico enfocado en el desarrollo de aplicaciones web conectadas a bases de datos empresariales.
